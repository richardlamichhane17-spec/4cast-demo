# 4CAST demo

Klikkbar demo av 4CAST, en app der ansatte i dagligvarebutikker registrerer tyveri og mistenkt tyveri, og butikksjefen vurderer hendelsene og ser statistikk.

**Alle tall og navn i demoen er oppdiktet.** Demoen lagrer ingenting.

Hele demoen ligger i index.html og trenger ingen server eller installasjon.
